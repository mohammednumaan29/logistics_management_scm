OPERATOR GUIDE

Help & Support

Quick guidance for day-to-day warehouse recovery operations.

Monitor shipments

Use Shipments to search and filter the available shipment records. Open Details to review linked products and recovery assignments. Shipment data is read-only.

Review warehouse stock

Use Warehouses for capacity and associated product records, and Inventory for on-hand, reserved, available, and reorder values. Daily demand is shown when present in the backend feed.

Open recovery assignments

Recovery Assignments lists only approved, execution-authorized plans with tasks assigned to the Warehouse Operator role in the current backend dataset. The backend enforces assignment ownership on every update.

Report progress

Open Recovery Tracking, select an assigned plan, then report a completion percentage and accepted status. Include a milestone, blocker, or operational note as relevant. Updates are submitted to the backend API.

Recovery statuses

Pending has not started. In progress is active work. Completed reports finished assigned work. Blocked identifies work that cannot proceed and should include a blocker description.

Access and support

This workspace uses JWT authentication with backend role checks. Every update is authorized by the backend; never treat this page as a permission boundary.
